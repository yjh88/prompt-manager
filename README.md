# 나만의 프롬프트 관리 프로그램

GenAI 미션을 진행하며 쌓인 프롬프트를 한곳에서 관리하는 **Python 콘솔 프로그램**입니다.
프롬프트를 카테고리별로 분류하고, 키워드로 검색하고, 자주 쓰는 항목은 즐겨찾기(⭐)로 관리할 수 있습니다.

> 데이터는 프로그램 실행 중에만 유지되며, 종료하면 기본 데이터로 초기화됩니다.

## 실행 방법

- 요구 사항: Python 3.10 이상 (외부 라이브러리 필요 없음)

```bash
git clone <저장소 URL>
cd prompt-manager
python main.py        # macOS/Linux에서 python이 없으면 python3 main.py
```

## 기능 목록

| 번호 | 기능 | 설명 |
|------|------|------|
| 1 | 프롬프트 추가 | 제목, 내용, 카테고리를 입력해 등록 (빈 값이면 재입력, 즐겨찾기 기본값 False) |
| 2 | 프롬프트 목록 | 전체 프롬프트를 번호, 카테고리, 즐겨찾기 표시(⭐)와 함께 출력 |
| 3 | 카테고리별 조회 | 카테고리를 선택해 해당 프롬프트만 출력 |
| 4 | 프롬프트 검색 | 키워드가 제목 또는 내용에 포함된 프롬프트 검색 (대소문자 무시) |
| 5 | 프롬프트 상세 보기 | 번호를 입력해 제목, 카테고리, 즐겨찾기 여부, 내용 전체 확인 |
| 6 | 즐겨찾기 관리 | 번호를 입력해 즐겨찾기 추가/해제 (토글) |
| 7 | 즐겨찾기 목록 | 즐겨찾기한 프롬프트만 모아서 보기 |
| 0 | 종료 | 프로그램 종료 |

목록, 검색, 카테고리 조회 결과의 번호는 전체 목록 기준이라, 그 번호를 그대로 상세 보기(5)와 즐겨찾기 관리(6)에 쓸 수 있습니다.

## 프롬프트 카테고리

| 카테고리 | 용도 |
|----------|------|
| 텍스트 생성 | 블로그, 이메일 등 글쓰기 프롬프트 |
| 이미지 생성 | 썸네일, 일러스트 등 이미지 생성용 키워드/지시문 |
| 영상 생성 | 광고 스크립트, 영상 시나리오 |
| 페르소나 | 특정 역할/전문가로 답하게 하는 설정 |
| 자동화 | 요약, 분류 등 반복 작업용 프롬프트 |
| 기타 | 위에 속하지 않는 프롬프트 |

프롬프트 추가 시 목록에 없는 카테고리를 직접 입력하면 새 카테고리로 등록됩니다.

## 코드 구조

| 함수 | 역할 |
|------|------|
| `show_menu()` | 메인 메뉴 출력 |
| `add_prompt()` | 프롬프트 추가 (`input_required()`, `select_category()` 사용) |
| `show_list()` | 전체 목록 출력 |
| `show_by_category()` | 카테고리별 조회 |
| `search_prompt()` | 키워드 검색 |
| `show_detail()` | 상세 보기 (`read_prompt_number()`로 번호 검증) |
| `toggle_favorite()` | 즐겨찾기 추가/해제 |
| `show_favorites()` | 즐겨찾기 목록 |
| `main()` | 메뉴 입력 루프 |

데이터는 `prompts` 리스트에 `{"title", "content", "category", "favorite"}` 딕셔너리로 저장합니다.
